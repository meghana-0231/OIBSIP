# BMI Calculator

A beginner-level Python command-line application that calculates Body Mass Index (BMI) and classifies the result into standard health categories.

## Features

- Accepts weight in kilograms and height in meters
- Calculates BMI using the standard formula
- Classifies BMI as Underweight, Normal, Overweight, or Obese
- Displays BMI rounded to 2 decimal places
- Validates non-numeric input
- Validates negative and zero values
- Provides helpful error messages

## BMI Categories

- Underweight: BMI < 18.5
- Normal: BMI 18.5 - 24.9
- Overweight: BMI 25 - 29.9
- Obese: BMI >= 30
