# Basic Weather App

A simple Python-based weather application that fetches real-time weather information for a user-specified city or ZIP code using the OpenWeatherMap API.

## Features

- Accepts a city name or ZIP code
- Fetches real-time weather data
- Displays temperature in Celsius and Fahrenheit
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles invalid/empty input
- Handles API/network errors
- Allows multiple searches
- Provides an option to exit

## Technologies Used

- Python
- Requests library
- OpenWeatherMap API

## How to Run

1. Install the required library:
   `pip install -r requirements.txt`

2. Add your OpenWeatherMap API key to `weather_app.py`.

3. Run:
   `python weather_app.py`

4. Enter a city name or ZIP code when prompted.
