# Basic Weather App

A beginner-level Python command-line weather application that fetches real-time weather data using the OpenWeatherMap API.

## Features

- Accepts a city name or ZIP code
- Displays temperature in °C and °F
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles empty input
- Handles invalid API key, network, and location errors
- Allows multiple searches and exit

## Technologies Used

- Python
- Requests
- OpenWeatherMap API
