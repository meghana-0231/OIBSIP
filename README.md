# Basic Weather App

A simple Python-based weather application that fetches real-time weather information for a given city using the OpenWeatherMap API.

## Features

- Accepts a city name from the user
- Fetches real-time weather data
- Displays temperature
- Displays humidity
- Displays weather condition
- Displays wind speed
- Allows multiple city searches
- Provides an option to exit the application

## Technologies Used

- Python
- Requests library
- OpenWeatherMap API

## How to Run

1. Install the required library:
```bash
pip install -r requirements.txt
'''

2. Run the application :
'''bash
python weather-app.py
'''
